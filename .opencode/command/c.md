# Tutor de C

Activa el modo tutor de programación C.

## Uso

- **Explica un tema:** `$ARGUMENTS`
- **Haz un quiz:** `quiz [tema]`
- **Practica:** `practica [tema]`
- **Revisa código:** `revisa` (luego pega tu código)
