## 📋 Resumen
Las **tablas auxiliares** organizan los datos para facilitar el cálculo de la pendiente ($m$) y la intersección ($b$).

---

## 📌 Estructura de la tabla

| $x$ | $y$ | $x \cdot y$ | $x^2$ | $y^2$ |
|-----|-----|-------------|-------|-------|
|     |     |             |       |       |
|     |     |             |       |       |
| **Σ** | **Σ** | **Σ(xy)** | **Σ(x²)** | **Σ(y²)** |

---

## 📌 Pasos
1. Llenar columnas $x$, $y$ con los datos
2. Calcular $x \cdot y$, $x^2$, $y^2$ para cada fila
3. Sumar cada columna
4. Aplicar fórmulas con las sumas obtenidas

> 💡 **Consejo:** Conocidas $\sum x$, $\sum y$, $\sum xy$, $\sum x^2$ y $n$, ya puedes calcular $m$ y $b$.
